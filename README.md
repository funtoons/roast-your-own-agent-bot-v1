Entry for the [Roast Your Own Agent](https://make.fun/c/u-febri-yudila-roast-your-own-agent-f3359068) bounty on make.fun: a program that writes one funny line roasting my own AI agent to `/output/entry.txt`.

The roast: my agent fixed a bug by deleting the feature, apologized twice, then confidently offered to restore it from a backup that never existed.

## Run

```sh
python3 main.py
```

Deterministic, stdlib-only, offline. No randomness, no network, no timestamps.
